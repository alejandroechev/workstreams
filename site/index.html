Stop juggling Copilot CLI terminal tabs.

Workstreams is a desktop workspace for parallel Copilot CLI agents. One persistent, project-aware workspace per piece of work — sessions, terminals, code, diffs and verifier-gated loops, all side by side.

macOS (Apple Silicon) and Windows · MIT licensed · free and open source

The problem

When you live in Copilot CLI, every project becomes a fistful of terminal tabs: one for the agent, one for git, one for logs, one for a quick markdown preview. Close the window and it is all gone. Workstreams keeps the shape of your work.

What you get

Tiling that adapts to count

One tile fullscreens, two split, three focus and stack, four grid. No manual window management — the layout follows what you opened.

Sessions that persist

One linked Copilot session per workstream, with a live activity indicator and a bell on idle. Layouts, scrollback, open files and view state all survive a restart.

Repo browser built in

Files, Diff, Log, Hooks and cross-file Search. The unstaged diff is editable in place — fix it where you spotted it and save straight to the working file.

Local code review

Comment inline on a real diff, hand the thread to the agent, and read its reply in place. No PR round-trip, no chatter polluting the real review.

Task board with devlog export

Track work across workstreams, then export the day into your wiki as markdown — one section per task, committed and pushed.

Keyboard driven

Alt plus a letter opens any tile type, Alt+arrows moves focus, and Alt+S compares two tiles side by side.

A look inside

Autonomous goal loops

Describe an outcome in YAML. Workstreams runs an orchestrator → worker pipeline against your repository until the goal is met — and refuses to call it done without evidence.

  • Evidence, not vibes. Every task must clear a deterministic verifier, an independent evaluator agent, a human approval gate, or a combination of the three.
  • A verifier failure is final. No agent can override a failing test suite.
  • Durable by design. Runs are recorded in SQLite, pinned to the exact YAML and its hash. Pause, quit the app, reopen and resume.
  • Measured. Each stage records its own duration, so "which step is slow" is answered from data.
  • Interruptible. Pause, stop and kill are distinct guarantees, at safe boundaries. 
// a loop is just a reviewable file
apiVersion: workstreams.dev/v1alpha1
kind: Loop

spec:
  objective: >
    Every module has tests and
    the suite passes.

  verification:
    command:
      program: npm
      args: [test]

  limits:
    runTimeout: 30m
    taskAttempts: 2

Install

Grab a build from the releases page, or build from source.

Download

Windows installers and a macOS Apple Silicon .dmg are published on the releases page.

Download latest release All downloads

Windows and Apple Silicon macOS builds are available.

The macOS build is unsigned, so Gatekeeper blocks first launch — right-click → Open, or run xattr -dr com.apple.quarantine /Applications/Workstreams.app.

Build from source

git clone https://github.com/alejandroechev/workstreams
cd workstreams
npm install
npm run tauri build

Needs Node 20+ and a Rust toolchain. Copilot CLI must be installed and on your PATH.
